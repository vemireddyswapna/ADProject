ABOUT THE PROJECT

Making Cell Classification Smarter with AI

An academic project exploring deep learning for cervical cell image classification using transfer learning.

Project Overview

Cervical Cell AI uses an EfficientNetB0 deep-learning model to classify cervical cell images into five cytological categories. The application provides predictions, confidence scores, saved prediction history, and PDF reports.

🎯

Objective

Explore automated classification of cervical cell images.

🧠

Deep Learning

Apply EfficientNetB0 transfer learning to image classification.

📄

Reports

Store prediction records and generate downloadable reports.

Developed By

Vemireddy Swapna

Department of Computer Science and Engineering

Malla Reddy University

This is an academic prototype. Its predictions and project-defined risk indicators are not a clinical diagnosis.
